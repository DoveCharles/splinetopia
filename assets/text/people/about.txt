# TRAITS
# Put any of these in {curly brackets} after an entry, and whoever gets that entry gets the trait:
#
#     Energy drinks {speed = 2.5}
#     Naps {lounging = 5, speed = 0.8}
#     Moonwalking {backwards}
#
# Separate several with commas (or give each its own brackets). A trait with no value, like {backwards}, is switched on.
# In loves and hates, `Card text | spoken text` gives how it's said aloud (see speech/about.txt), [placeholders] fill in
# a word per person, and <tastes, vice> puts it in those speech categories.
# Moods, enjoys, hates (even names) can all have traits, and someone's traits stack up: they multiply together — two
# entries with speed = 2 make someone four times as fast — except mood and the eye looks (happy, sad, angry, shock),
which add up. Everyone starts at the value in
# brackets below, and a value outside a trait's range is kept to it. A misspelt trait is ignored (and says so in the
# browser's console).
#
#   trait       start   what it does                                                                    range
#   speed   1       how fast they walk — 2 is twice as fast, 0.5 half                               0.1 to 6
#   size        1       how big they are — 1.3 is 30% taller, 0.7 30% shorter                           0.3 to 3
#   chatty      1       how often they stop to talk to people — 0 never does                            0 to 10
#   talkative   1       how much of the talking they do in a conversation, and how long they go on     0.05 to 20
#   lounging    1       how often they sit down on benches or the grass, or lie down in a park          0 to 10
#   patience    1       how long they stick at things — standing about, sitting, lying, chatting        0.1 to 10
#   fidgety     1       how often they scratch or have a think while standing about — 0 never           0 to 20
#   nosy        1       how often they look around, and how far round                                  0.05 to 10
#   blinks      1       how often they blink — 0 never does (unsettling)                               0 to 20
#   parks       1       how likely they are to wander into a park they walk past — 0 never              0 to 8
#   plazas      1       how likely they are to wander into a plaza they walk past — 0 never             0 to 8
#   roadsafety  1       how big a gap in traffic they wait for before crossing a road — 0.2 barely looks 0.2 to 3
#   agemult     1       multiplies age, suiting traits to younger or older people                      0.1 to Inf
#   mood        0       their resting face — -1 a frown, 1 a smile (and it tints their reactions)       -1 to 1
#   happy       0       how happy their eyes look                                                      0 to 1
#   sad         0       how sad their eyes look                                                        0 to 1
#   angry       0       how angry their eyes look                                                      0 to 1
#   shock       0       how shocked their eyes look                                                    0 to 1
#   evil        0       how evil they are, the reactions of others when they die                       -1 to 1
#   weight      1       how much a car slows when it hits them, multiplying a small base (always far less than hitting a car)  0.1 to 10
#   aggression  1       how likely they are to punch sommone                                           0 to 20
#   bloodlust   off     covered in blood, they run twice as fast and go about punching everyone they can  on or off
#   backwards   off     they walk backwards                                                           on or off
#   dodge       0       the chance of leaping clear of a punch, then going after whoever threw it      0 to 1
#   blazed      off     the whites of their eyes are slightly red, like they're high                   on or off
#   vampire     off     adds the traits in TRAIT_MACROS (core/traits.js), skin pales with age                on or off
#   ageless     off     they don't visibly age, hair does not grey                                    on or off
#   choiceweight 0       whole numbers, how likely to appear, set 0 to disable autoassign               0 to Inf

# CURRENT DISTRIBUTION
# A [distribution] section says how many of each counted attribute a thing gets. Counted attributes are the ones that can
# hold several values at once: here, enjoys (their loves) and hates. It's read once for the whole file and applies to
# everyone alike, so it belongs at the top with the trait table, not inside a list. Every other kind of thing reads its own
# file the same way — cars.txt, buildings.txt, trains.txt and bees.txt each have their own [distribution], and any file
# without one falls back to the same spread written below.
#
# Each row is one count per counted attribute (loves, then hates), then `@` and how likely that row is against the others.
# Leave the weight out and it's 1. Rows with no weight at all are all equally likely.
#
#   loves, hates @ weight
#   1, 1 @ 0.6            60% of people: one love, one hate
#
# SOLO: { solo } on an enjoy or a hate makes it the only one of its kind that person has: a solo enjoy means no other
# enjoys, a solo hate no other hates. The other side is unaffected, so they can end up with just that one entry.
#
# ------------------------------------------------------------------------------------------------------------------------
#
# LIMITATIONS!!!
# Limits can be used to prevent nonsensical combinations, and are called just like ordinary traits, with a few exceptions:
# Limits are numbered, and have a polarity: Rule 1a is incompatible with 1b, 33b incompatible with 33a, and so on.
# A limit is stated as: { limit = 1a }
# To put multiple limits, use commas: { limit = 1a, limit = 3b}
# Existing limits below:
#
#   1.      Vampirism:       a = Vampiric, b = Harmful to vampires
#   2.      Times:           a = Morning person, b = Night person
