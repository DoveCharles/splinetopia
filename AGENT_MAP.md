# Agent map — Kallipolis

Browser city-blockout tool on three.js (plain ES modules, no build step). Read this first; open only the files you need.

## Rules for agents
- Never list or search `.git/` or `assets/models/` (binary .glb, ~14 MB). Exclude them from any recursive listing.
- Search (grep) for a symbol, then read only the relevant line range. Files over ~40K are marked **big**; never read those whole.
- `S` / `App` in `src/core/shared.js` hold cross-module state; start there when tracing data flow.
- Update this map in the same change whenever files are added, moved, renamed or deleted.
- Log notable decisions in the project doc `claude/decisions.md`.
- Speech (`src/life/speech-text.js`, format in `assets/text/speech/about.txt`) must know about new things people could talk about. When adding or changing a way people die or something people could notice (a `cause` in killPerson/drownedPerson, or a witness/notice/feel call in people.js → SEEN_RANK there, SIGHTS/DEATHS/FEELINGS in speech-text.js), a trait (TRAITS — read automatically, but list any worth mentioning in about.txt), a world value (weather, time, morality → WEATHERS / worldAllows), a building kind or room layout (`here.building`), or anything else a line could react to: update speech-text.js and about.txt's lists, and add example lines.

## Root
- `index.html` (22K) Page markup, panel DOM, importmap (three.js from CDN), Clipper from CDN. Links the CSS below.
- `css/` Styles, linked in cascade order: `base.css` (core layout, panel, cards), `win3.css` (Windows 3.0 theme, `html.win3`), `touch.css` (touch & small screens), `phone.css` (≤760px layout), `ped.css` (possession/driving view).
- `style.css` Stub; unused (split into `css/`). Safe to delete.
- `src/ui/meter.css` Reusable meter component. `src/ui/morality.css` superseded, unlinked.
- `serve.py` Dev server with no-store caching: `python3 serve.py [port]`. Also writes `assets/text/index.txt` (every .txt under assets/text/, for the speech loader) and `assets/music/index.txt` (every .mid under assets/music/, for audio/pub-music.js) on start and whenever they're fetched; `python3 serve.py --index` only writes them. `.claude/launch.json` lists ports 8743–8753.
- `netlify.toml` Deploys repo root as-is; push to `main` redeploys.
- `README.md` Feature overview. `jsconfig.json` JS type-check settings for `src/`.

## assets/
- `text/*.txt` Editable data read by `src/core/entries.js`: `text/people/` (one file per list: `about.txt` — notes, trait table, [distribution] — `boynames`, `girlnames`, `unisexnames` (into both), `surnames`, `nicknames`, `moods`, `loves`, `hates`; joined in order under their headings by life/profiles.js PEOPLE_FILES), `cars.txt`, `buildings.txt`, `bees.txt`, `pigeons.txt`, `planes.txt`, `trains.txt`, `tv.txt` (YouTube links or direct video file URLs), `morality.txt`, `text/index.txt` (generated by serve.py; commit it). `music/` The pubs' music: drop any `.mid` in (subfolders too) and every pub plays it (audio/pub-music.js); `music/index.txt` is generated by serve.py (commit it); `music/TimGM6mb.sf2` is the General MIDI sound bank they're played with (Tim Brechbill, GPL v2). `text/speech/` (what people say and think, in subfolders as you like — subjects like [tastes] come from <tastes> on people's loves/hates; words/topics/topics.txt gathers them: one category per file, named by file — words with forms, conversations with > replies, thoughts, {tags}, world limits, loves/hates; format in `speech/about.txt`; read by src/life/speech-text.js). `dictionary.txt` is unused (replaced by speech/).
- `icons/*.png` Every UI icon (and each coloured state: `-on`, `-open`, `-hidden`) as a hand-drawn 16x15 bitmap, shown in place of the SVGs by src/ui/pixel-icons.js; pure black pixels take the text colour.
- `models/*.glb` Blender exports (people, hair, outfits, furniture sets, vehicles). Generated by `tools/*-models.py`.
